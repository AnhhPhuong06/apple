Đưa app lên website

  1. Thêm app và tải apps.js.
  2. Với file trong repository: bấm Lưu IPA dưới tên app, rồi đặt file đó vào thư mục downloads/.
  3. Commit các file vào GitHub.
  4. Mở Settings → Pages, chọn nhánh main và thư mục / (root).
